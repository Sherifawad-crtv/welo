# Welo

Calorie and deficit tracker. React + Vite PWA.

```
npm install
npm run dev       # http://localhost:5173 (also on your LAN for phone testing)
npm run build     # outputs dist/
npm run preview
```

## Structure

- `src/App.jsx`: navigation state (tab, settings, entry sheet)
- `src/screens/`: `Progress` (Week and Weight views), `Settings`
- `src/components/`: `Hero`, `Entries`, `Macros`, `NavBar`, `EntrySheet`, `Icons`
- `src/data.js`: sample data (replace with real state or an API)
- `src/styles.css`: all styles (tokens in `:root`)
- `public/icons/`: app icons. The manifest and service worker are generated by `vite-plugin-pwa` in `vite.config.js`.

## Layout

Phones: the app fills the screen, with safe-area insets at the top and inside the bottom tab bar. Desktop (481px and up): framed 428×926 mockup with a fake status bar. Fonts are bundled (Roboto, Bricolage Grotesque), so they work offline.

## Deploy on Vercel

Import the repo, framework preset **Vite** (auto-detected). Test the install on the HTTPS URL: Add to Home Screen, then launch from the icon. A regular browser tab keeps its own toolbar, which the page can't draw over.

## Icons

[Solar icon set](https://icon-sets.iconify.design/solar/) (CC BY 4.0). Run `node scripts/gen-icons.mjs` after adding a name to its list to regenerate `src/solarIcons.js`, then use `<Sol name="..." />`.
